🚀 Inception

Building a secure web infrastructure with Docker & DevOps.

About the Project

Inception is a system administration and DevOps project from the 42 curriculum. The objective is to design a secure and scalable web infrastructure using Docker containers while learning networking, virtualization, and service orchestration.

Infrastructure Services

🌐 NGINX

Serves as the entry point of the infrastructure, handling HTTPS traffic with TLS encryption and forwarding requests securely.

🐘 WordPress + PHP-FPM

Runs the WordPress application while PHP-FPM efficiently processes dynamic PHP requests.

🗄️ MariaDB

Stores all website data including users, posts, settings, and application content.

🐳 Docker

Docker packages applications with all their dependencies into lightweight containers, making deployments consistent, portable, and reproducible across environments.

⚙️ DevOps

DevOps combines software development and IT operations to automate deployment, improve collaboration, increase reliability, and enable faster software delivery.
