Core Concepts

Containerization

Docker

Docker packages an application and its dependencies into an isolated container that can run consistently across environments.

Orchestration

Docker Compose

Compose defines multiple services, networks, volumes and their configuration in one YAML file.

Web Server

NGINX

NGINX receives HTTP/HTTPS requests and acts as the entry point to the infrastructure.

Security

TLS

TLS encrypts communication between the browser and the server, protecting data transmitted over HTTPS.

CMS

WordPress

WordPress is the application running inside its own container and generates the website content.

PHP

PHP-FPM

PHP-FPM executes PHP scripts for WordPress. NGINX communicates with it through FastCGI.

Database

MariaDB

MariaDB stores WordPress data such as users, posts, settings and metadata.

Persistence

Volumes

Docker volumes keep important data persistent even when containers are stopped or recreated.

Networking

Docker Network

Containers communicate with each other through an isolated Docker network using service names as DNS.

Configuration

Environment Variables

Environment variables allow configuration values such as database names and usernames to be passed to containers.

Security

Secrets

Sensitive credentials such as database passwords can be stored separately from the application configuration.

Images

Dockerfile

A Dockerfile describes how a container image is built, including the base image, packages and configuration.

The Big Picture

The Inception infrastructure is composed of several independent containers that work together.
